# GEOINQUIRE Risk Workshop – Potsdam 2026

Welcome to the GEOINQUIRE Risk Workshop. This repository serves as the central entry point for the workshop materials, documentation, and software.

## Lecture Notes

The workshop lecture notes are available here:
- **PTRA Lecture Notes**:   https://github.com/eurotsunamirisk/PTRALectureNotes

## Workshop Repositories

| Repository                                                                                                                                                                                                | Description                                              |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| [BayesianEmpiricalFragilityModelling](https://github.com/eurotsunamirisk/BayesianEmpiricalFragilityModelling)                                                                                             | Bayesian empirical fragility modelling                   |
| [VulnerabilityModellingviaFragilityConsequenceConvolution-DeterministicConsequence](https://github.com/eurotsunamirisk/VulnerabilityModellingviaFragilityConsequenceConvolution-DeterministicConsequence) | Vulnerability modelling using deterministic consequences |
| [VulnerabilityModellingviaFragilityConsequenceConvolution-ProbabilisticConsequence](https://github.com/eurotsunamirisk/VulnerabilityModellingviaFragilityConsequenceConvolution-ProbabilisticConsequence) | Vulnerability modelling using probabilistic consequences |
| [HumanExposureModeling](https://github.com/eurotsunamirisk/HumanExposureModeling)                                                                                                                         | Human exposure modelling                                 |
| [ConvolutionBasedPTRA](https://github.com/eurotsunamirisk/ConvolutionBasedPTRA)                                                                                                                           | Convolution-based probabilistic tsunami risk assessment  |
| [SimulationBasedPTRA_Building](https://github.com/eurotsunamirisk/SimulationBasedPTRA_Building)                                                                                                           | Simulation-based PTRA for buildings                      |
| [SimulationBasedPTRA_Human](https://github.com/eurotsunamirisk/SimulationBasedPTRA_Human)                                                                                                                 | Simulation-based PTRA for human risk                     |

## Download all repositories

### Linux / macOS

```bash
bash setup.sh
```

### Windows

Double-click

```text
setup.bat
```

or run it from Command Prompt.
